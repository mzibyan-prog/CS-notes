1. Database Concepts DBMS · Data Integrity · Data Models

▼

A Database Management System (DBMS) allows users to define, create, maintain and control access to the database.

Key concepts:

ConceptDescription
Data ModelDefines the logical structure of a database (e.g., relational model)
Data IntegrityEnsures accuracy and consistency of data stored in the database
Data StorageHow data is organized in files and tables within a DBMS
DatabaseOrganized collection of data that can be easily accessed, managed, and updated
📌 Exam tip: Be prepared to explain the role of a DBMS and the importance of data integrity in outcomes based on user inputs.

2. Database Models Hierarchical · Network · Relational · Object-oriented

▼

Different database models determine how data is stored and accessed:

ModelDescriptionExample
HierarchicalUses parent-child relationships in a single tree structureXML data
NetworkAllows more complex relationships with many-to-many linksOlder database applications (e.g., Integrated Data Store)
RelationalRepresents data in tables; enables logical relationshipsMySQL, PostgreSQL
Object-orientedStores data as objects, encapsulating both data and behaviordb4o, ObjectDB
Why relational model is dominant: It simplifies database design and management with SQL (Structured Query Language) universally accepted for interfacing.

3. Relational Databases Tables · Keys · Relationships

▼

In a relational database, data is represented in tables (relations) that contain rows (records) and columns (attributes).

TermDescription
Primary KeyUniquely identifies a record in a table
Foreign KeyA reference to a primary key in another table, creating a link between them
RelationshipDefines how data in different tables are related (one-to-one, one-to-many, many-to-many)
📌 Exam tip: You might be asked to explain how primary and foreign keys enforce referential integrity in relational databases.

4. SQL & Queries SELECT · INSERT · UPDATE · DELETE

▼

SQL is the standard language used to communicate with relational databases. Key SQL statements:

StatementDescription
SELECTRetrieves data from one or more tables
INSERTAdds new data/records into a table
UPDATEModifies existing data within a table
DELETERemoves data/records from a table
Example SELECT statement: SELECT * FROM Students WHERE Age > 18; Retrieves all columns from the 'Students' table where 'Age' is greater than 18.

5. Database Design Normalization · ER Diagrams

▼

Effective database design ensures data integrity and efficiency. It includes concepts like:

ConceptDescription
NormalizationProcess of structuring tables to minimize redundancy (e.g., converting to 1NF, 2NF, 3NF)
ER DiagramsVisual tool to map out entities, relationships, and attributes in a database

6. Normalization 1NF · 2NF · 3NF

▼

Normalization ensures that the database is logically organized. It includes:

FormBasic Definition
1NF (First Normal Form)No repeating groups; all attributes contain atomic values
2NF (Second Normal Form)All non-key attributes are fully functionally dependent on the primary key
3NF (Third Normal Form)No transitive functional dependencies; all attributes are directly dependent on the primary key

📝 Past paper questions — Unit 8

▼
Q1What is a DBMS, and what are its main functions? [4]
📋 Show MS
A DBMS is software that manages databases; functions include data definition, data manipulation, data retrieval, and data integrity.
Q2Compare hierarchical and relational database models. [4]
📋 Show MS
Hierarchical: tree-like structure with parent-child relationships; Relational: data in tables with relationships using keys.
Q3Explain the purpose of primary keys and foreign keys in relational databases. [4]
📋 Show MS
Primary key uniquely identifies records in a table; foreign key links to primary key in another table, establishing relationships.
Q4What are the main components of an SQL statement? [3]
📋 Show MS
Components include the action (e.g., SELECT), the target table (e.g., FROM table_name) and conditions (e.g., WHERE condition).
Q5Describe the two types of normalization: 1NF and 2NF. [4]
📋 Show MS
1NF requires no repeating groups and atomic values; 2NF removes partial dependency by ensuring all non-key attributes depend on the whole key.
Q6What is the purpose of ER diagrams in database design? [2]
📋 Show MS
To visually represent entities, their relationships, and attributes, helping in understanding database structure.
Q7What is the difference between a relational model and a network model? [3]
📋 Show MS
Relational model uses tables and relationships; network model uses nodes and more complex relationships, allowing many-to-many links.
Q8Explain a scenario where using a natural language interface to a DBMS would help users. [2]
📋 Show MS
Allows non-technical users to query the database in plain language, enhancing accessibility for those unfamiliar with SQL or complex queries.
