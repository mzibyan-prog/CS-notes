1. Security Threats Hacking · Phishing · Pharming

▼

Data security protects systems from threats. The main threats:

ThreatWhat it isEffectHow to guard against it
HackingGaining unauthorised access to a systemData theft, system damage, loss of privacyFirewalls, strong passwords, regular updates, intrusion detection
MalwareMalicious software (viruses, worms, trojans)Corrupts/deletes data, slows system, steals infoAntivirus/anti-spyware, not opening suspicious attachments
PhishingFake emails/websites pretending to be trusted sourcesVictim reveals bank/credit card detailsUser awareness, anti-phishing toolbars, checking sender/URL
PharmingRedirecting users from a real website to a fake oneDetails captured without user clicking a linkKeep software updated, secure DNS, check for https/padlock
📌 Exam tip: The syllabus asks you to explain the effect of a threat AND how to guard against it — always answer both parts.

2. Types of Malware Virus · Worm · Trojan · Logic bomb · Bot · Spyware

▼
TypeDefinitionBehaviour
VirusMalicious code that attaches to a host fileReplicates when file is opened; needs human action to spread
WormSelf-replicating programSpreads without user action, across networks; uses up bandwidth
Trojan horseMalicious program disguised as legitimate softwareReplaces part of legit software to harm system; does not self-replicate
Logic bombMalicious code activated by a conditionLies dormant until a trigger (e.g. a date) then deletes files/sends data
BotInternet robot (not always harmful)Can take control of a system to launch attacks (botnet)
SpywareSecretly monitors user activityKey logging (records key presses); sends data back to attacker
📌 Exam tip: Difference between virus and worm — a virus needs user action (opening a file) to spread; a worm spreads automatically over a network.

3. Data Privacy & Data Protection 8 guiding principles

▼

Data privacy ensures personal data is not accessed by unauthorised parties. Data protection laws follow the same eight guiding principles in most countries:

#Principle
1Data must be fairly and lawfully processed
2Data can only be processed for the stated purpose
3Data must be adequate, relevant and not excessive
4Data must be accurate
5Data must not be kept longer than necessary
6Data must be processed in accordance with the data subject's rights
7Data must be kept secure
8Data must not be transferred to another country unless that country has adequate protection
Note: You may be asked to explain consequences of breaking these principles (e.g. fines, loss of trust, identity theft).

4. Authentication & Access Rights User accounts · Passwords · Access levels

▼

Authentication proves a user's identity. Access rights limit what each user can do.

Authentication methods:
  • Password / username — something you know
  • Biometrics (fingerprint, face) — something you are
  • Token / smart card — something you have
  • Two-factor / multi-factor (2FA/MFA) — combination of the above
Good vs poor passwords (exam example):
Poor passwordWhy weak
280290Date of birth — easily guessed from public info
FeLix1234Pet's name + predictable numbers
John04Uses real name + year
How to improve passwords:
1 Use 8+ characters mixing upper/lower case, numbers, symbols
2 Avoid dictionary words, names, dates
3 Use a passphrase (e.g. Purple$Train!Moon7)
4 Different password for each account; store in a password manager
5 Never save passwords on shared devices — beware "save password?" prompts

5. Firewalls & Anti-Malware Firewall · Antivirus · Anti-spyware

▼

A firewall controls traffic between a network and the outside world (often a gateway, or software in the OS).

Firewall limitations — it CANNOT: prevent insiders using their own modems to bypass it; control employee misconduct/carelessness; stop standalone users disabling it. These need management and user discipline.
SoftwareWhat it does
AntivirusChecks files before running; compares to known-virus database; heuristic checking; quarantines/deletes infected files (false positives possible)
Anti-spywareDetects/removes spyware using rules or known file structures
📌 Exam tip: Antivirus must be kept up to date (new viruses appear constantly) and full system scans done regularly — some viruses lie dormant.

6. Encryption Symmetric · Asymmetric · Block/Stream · Chaining

▼

Plaintext → ciphertext via an encryption algorithm. Encryption cannot stop interception but makes intercepted data unreadable.

TermMeaning
PlaintextReadable original data
CiphertextOutput of encryption
Symmetric encryptionOne shared secret key (fast, but key-distribution problem)
Asymmetric encryptionPublic key (everyone) + private key (secret); solves key distribution
Block cipherEncrypts fixed-size blocks together
Stream cipherEncrypts bit-by-bit in sequence
Block chainingPrevents identical plaintext blocks giving identical ciphertext
Key distribution problem: In symmetric encryption, sending the secret key risks interception by an eavesdropper. Asymmetric encryption solves this — only the private key is secret; the public key can be shared openly.

7. Digital Signatures, Certificates & PKI Hashing · SSL · CA

▼

A digital signature verifies a document's sender and that it was not tampered with. Its four purposes: authentication, non-repudiation, data integrity, confidentiality.

ConceptMeaning
HashingPlaintext → digest (fixed value); used to identify sender without encrypting whole message
Digital certificateIssued by a Certificate Authority (CA); proves website/owner identity + public key
PKIPublic Key Infrastructure: certificates + public-key crypto + CAs
SSL/TLSProvides confidentiality, authentication and message integrity (look for https + padlock)
How a digital signature works: Sender hashes the message → encrypts the digest with their private key. Receiver decrypts digest with sender's public key, re-hashes the message, and compares. Match = authentic and unaltered.

📝 Past paper questions — Unit 6

▼
Q1Explain the effect of these threats and how to guard against them: (i) hacking (ii) malware (iii) phishing (iv) pharming. [8]
📋 Show MS
Hacking: unauthorised access → use firewalls/strong passwords. Malware: corrupts data → antivirus, don't open suspicious files. Phishing: fake emails steal details → awareness, anti-phishing toolbar, check URLs. Pharming: redirect to fake site → updated software, secure DNS, check https.
Q2Define: worm, logic bomb, Trojan horse. [3]
📋 Show MS
Worm: self-replicating malware spreading without user action. Logic bomb: code triggered by a condition (e.g. date) to cause harm. Trojan: malware disguised as legitimate software.
Q3Why are the passwords 280290, FeLix1234, John04 poor? How could they be improved? [5]
📋 Show MS
Weak because they use DOB, pet name + numbers, real name + year — all guessable. Improve: 8+ chars, mix case/numbers/symbols, no dictionary words/names/dates, unique per account, use password manager.
Q4Explain why John should say 'no' to saving his password on a device. [2]
📋 Show MS
Saved passwords can be accessed by anyone using the device or by malware, compromising account security.
Q5Explain the difference between symmetric and asymmetric encryption. [4]
📋 Show MS
Symmetric: same key to encrypt/decrypt — fast but key distribution risk. Asymmetric: public key (shared) + private key (secret) — solves distribution problem but slower.
Q6State the biggest disadvantage of symmetric encryption. [1]
📋 Show MS
Security problem when transmitting the secret key (key distribution problem).
Q7Explain what a digital signature is and its four purposes. [5]
📋 Show MS
A digital code validating authenticity/integrity. Purposes: authentication, non-repudiation, data integrity, confidentiality.
Q8Explain what is meant by pharming and how it differs from phishing. [3]
📋 Show MS
Pharming silently redirects a real website to a fake one (no user click needed). Phishing requires the user to click a link/open an email first.
