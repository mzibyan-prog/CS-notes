1. Operating System Functions 5 key management tasks

▼

An operating system (OS) is system software that manages computer hardware and provides services for applications.

FunctionPurposeExamples
Memory ManagementAllocates/deallocates memory; moves data between RAM and virtual memoryPaging, segmentation, virtual memory
File ManagementCreates, deletes, moves, renames files; controls file accessFAT, NTFS, ext4 file systems
Security ManagementUser authentication, access rights, data encryptionPasswords, firewalls, permissions
Hardware ManagementCommunicates with devices via device driversPrinter drivers, USB controllers
Process ManagementLoads/unloads programs; handles multitaskingScheduling algorithms, task switching
📌 Exam tip: You must be able to name all 5 functions and give examples. Memory management often appears in questions about virtual memory or paging.

▼

A human-computer interface (HCI) lets users interact with a computer:

InterfaceDescriptionPros & Cons
GUI (Graphical UI)Visual: icons, windows, menus; WIMP (Windows, Icons, Menus, Pointing)✅ Intuitive, easy to learn
❌ Uses more memory/CPU
CLI (Command Line Interface)Text-based: user types commands✅ Powerful, fast for experts
❌ Hard to learn; no visual cues

❌ Recognition may fail
📌 Exam tip: Know the differences between GUI and CLI — GUI is easy for beginners but slower for experts; CLI is faster for experts but difficult to learn.

3. Memory Management Paging · Segmentation · Virtual Memory

▼

Memory management includes:

📊 Paging

Divides memory into fixed-size pages (e.g., 4KB). Programs are split across pages; OS maps pages to frames in RAM.

📊 Segmentation

Divides memory into logical segments (code, data, stack). Each segment has variable length; easier for programmers.

💾 Virtual Memory

Uses hard disk as extra "RAM". When RAM is full, inactive pages are swapped to disk (page file/swap file).

Swap process: Less-used pages → disk; needed again → back to RAM. Slower than RAM access but allows more programs.
TermMeaning
PageFixed-size block of memory
FramePhysical location in RAM that holds a page
Page TableMaps virtual addresses to physical addresses
ThrashingWhen system spends more time swapping than executing

5. Program Libraries DLLs · Reusable Code

▼

A program library contains ready-made code for common tasks (e.g., maths functions, graphics).

Dynamic Link Library (DLL) files are shared libraries in Windows. Programs link to them at runtime.

TypeWhen linkedExamplesPros & Cons
Static LibraryAt compile time.lib files (Windows)✅ Faster execution; ❌ Larger executable
Dynamic LibraryAt runtime.dll files (Windows), .so files (Linux)✅ Smaller executables, shared; ❌ DLL missing = program fails
Benefits of libraries: Code reuse (don't reinvent wheel), easier maintenance (update library once), smaller program size (shared libraries).

6. Language Translators Assemblers · Compilers · Interpreters

▼

Language translators convert source code to machine code:

TranslatorInputOutputKey features
AssemblerAssembly languageMachine codeOne-to-one mapping; machine dependent
CompilerHigh-level languageObject code (exe)Translates all at once; faster execution
InterpreterHigh-level languageExecutes directlyTranslates line by line; slower but easier to debug
Compiler vs Interpreter
AspectCompilerInterpreter
Translation timeBefore execution (compile once)During execution (every run)
Execution speedFast (machine code ready)Slower (translates each time)
Error detectionAll at compile timeStops at first error
PortabilityMachine specificCross-platform if interpreter exists
Example languagesC, C++, PascalPython, JavaScript, BASIC
📌 Exam tip: Java uses both! Java code → bytecode (compiler), bytecode → executed by JVM (interpreter).

8. Virtual Machines Guest OS · Host OS · Hypervisor

▼

A virtual machine (VM) is an emulated computer running inside another computer.

📊 Virtual Machine Architecture
ComponentRole
Host OSOriginal OS on physical computer
Guest OSOS running inside the VM
Hypervisor (VMM)Virtual Machine Monitor; creates/manages VMs
Benefits of VMs:
  • Hardware independence — run different OS on same hardware
  • Security — isolate risky programs in a VM
  • Testing — test software in different OS without rebooting
  • Resource sharing — one powerful server hosts many VMs
Limitations of VMs:
  • Performance overhead — slower than native OS
  • Complexity — needs expertise to manage
  • Resource competition — VMs share physical resources

📝 Past paper questions — Unit 5

▼
Q1Explain why a microwave oven does not need an operating system. [2]
📋 Show MS
It has a fixed, simple set of tasks; no need for complex resource management, multitasking, or user interface.
Q2Describe the main differences between a GUI and a CLI. [3]
📋 Show MS
GUI visual (icons, windows) vs CLI text-based. GUI easy for beginners, CLI faster for experts. GUI uses mouse/pointing, CLI keyboard commands.
Q3Explain two functions of an operating system. [4]
📋 Show MS
Memory management: allocates/deallocates memory, moves data to virtual memory. File management: creates/deletes files, controls access.
Q4Describe virtual memory and why it is used. [3]
📋 Show MS
Uses disk as extension of RAM. Inactive pages swapped to disk to free RAM. Allows more programs to run than physical RAM allows.
Q5Give three examples of utility software and their purposes. [3]
📋 Show MS Virus checker: scans for/removes malware. Backup software: creates data copies for recovery. Disk defragmenter: reorganises files for faster access.
Q6Compare compilers and interpreters. [4]
📋 Show MS
Compiler translates all at once (before execution), produces standalone executable, faster runtime. Interpreter translates line-by-line (during execution), slower but easier to debug.
Q7What is an IDE? Give three features. [4]
📋 Show MS
Integrated Development Environment. Features: code editor with syntax highlighting, debugger with breakpoints, compiler/interpreter integration, context-sensitive help.
Q8Explain the role of DLL files. [2]
📋 Show MS
Dynamic Link Libraries: contain reusable code that can be shared by multiple programs, loaded at runtime to reduce executable size.
