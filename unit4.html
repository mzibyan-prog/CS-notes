1. Registers & buses PC, MAR, MDR, CIR, ACC, IX

▼

Registers are small, ultra-fast storage areas in the CPU. Key registers:

RegisterFull namePurpose
PCProgram CounterStores the address of the next instruction to execute
MARMemory Address RegisterTemporarily stores the address before accessing memory
MDRMemory Data RegisterTemporarily stores data/instructions fetched from memory
CIRCurrent Instruction RegisterHolds the instruction currently being decoded and executed
ACCAccumulatorStores operands and results of arithmetic/logic operations
IXIndex RegisterUsed in indexed addressing; modified during loops
SRStatus RegisterHolds flags: Zero (Z), Carry (C), Negative (N), Overflow (V)

Buses are parallel pathways carrying data throughout the system:

BusDirectionCarriesNotes
Address busUnidirectional (CPU → Memory)Memory addressesWidth determines max addressable locations (e.g., 16-bit = 2¹⁶ = 65,536)
Data busBidirectionalData, instructions, or addressesWidth = word length (16-bit, 32-bit, 64-bit)
Control busBidirectionalControl signals (read, write, interrupt)Usually 8-bit; synchronised by system clock
📌 Exam tip: Understand the role of each register in the fetch-execute cycle. Know that the address bus is unidirectional but the data bus is bidirectional.

2. Fetch-execute cycle Three stages: Fetch, Decode, Execute

▼

The fetch-execute cycle is the basic operation of every CPU. It repeats continuously.

🔄 STAGE 1: FETCH
1 PC → MAR via address bus (PC holds address of next instruction)
2 Memory[MAR] → MDR via data bus (fetch instruction from memory)
3 MDR → CIR (move instruction into current instruction register)
4 PC ← PC + 1 (increment PC to point to next instruction)
🔍 STAGE 2: DECODE
5 Control Unit interprets the instruction in the CIR
6 Extract opcode and operand
⚡ STAGE 3: EXECUTE
7 Control Unit sends signals to appropriate components
8 Instruction is carried out (e.g., ALU adds, data is stored)
✏️ Past paper: You may be asked to describe all three stages or trace through a fetch-execute cycle step by step.

3. Register Transfer Notation (RTN) Notation for register changes

▼

Register Transfer Notation (RTN) is a shorthand to describe fetch-execute steps:

NotationMeaningExample
[X]Contents of register X[PC] = contents of PC
X ← [Y]Contents of Y copied to XMAR ← [PC] (PC copied to MAR)
[[X]]Contents of the memory location whose address is in XMDR ← [[MAR]] (fetch from memory at MAR)
[X] + 1Add 1 to contents of XPC ← [PC] + 1 (increment PC)
Fetch-Execute Cycle in RTN: MAR ← [PC] ← PC → MAR (address bus) MDR ← [[MAR]] ← Memory address sent, instruction fetched CIR ← [MDR] ← Instruction moved to CIR PC ← [PC] + 1 ← PC incremented (Decode and Execute follow)
Frequent Paper 1 Q Describe in RTN the steps to fetch an instruction. [4]
📋 Show mark scheme
MAR ← [PC] (address of next instruction) MDR ← [[MAR]] (fetch instruction from memory) CIR ← [MDR] (instruction moved to CIR) PC ← [PC] + 1 (increment PC)

4. Interrupts Priority, ISR, context switching

▼

An interrupt is a signal that pauses the current program and requests the CPU's attention.

Sources of interrupts: hardware (I/O device ready, timer, error) or software (illegal instruction, divide-by-zero).

Priority determines the order interrupts are serviced. Higher-priority interrupts may interrupt lower-priority ones.

1 During fetch-execute, the interrupt register is checked
2 If an interrupt is set, the CPU checks its priority
3 CPU stores the current state (PC, registers, status) — context save
4 Jump to the Interrupt Service Routine (ISR)
5 ISR executes
6 Restore saved context — context restore
7 Return to original program
📌 Exam tip: Interrupts enable multi-tasking and allow I/O operations without wasting CPU time. Context save/restore is essential to resume the original program correctly.

5. Assembly language basics Opcode, operand, mnemonics

▼

Assembly language uses mnemonics instead of raw binary machine code.

Each instruction has an opcode (operation) and an optional operand (data or address).

Instruction format: [Label:] OPCODE OPERAND Example: loop: ADD total ← Label points here; ADD is opcode; total is operand

✏️ Note: A label marks a location in the program so you can jump to it. Labels end with : and are used with jump instructions.

6. Instruction types Load, Store, Arithmetic, Compare, Jump

▼

Assembly language instructions are grouped by function:

📥 Data movement instructions:
  • LDM #value — Load immediate (load a constant)
  • LDD address — Load direct (fetch from memory)
  • LDI address — Load indirect (fetch via pointer)
  • LDX address — Load indexed (fetch with offset)
  • STO address — Store ACC at address
➕ Arithmetic instructions:
  • ADD address or ADD #n — Add to ACC
  • SUB address or SUB #n — Subtract from ACC
  • INC register — Increment (ACC or IX)
  • DEC register — Decrement (ACC or IX)
🔀 Control/comparison instructions:
  • CMP address or CMP #n — Compare ACC with value (sets flags)
  • CMI address — Compare indirect
  • JMP address — Unconditional jump
  • JPE address — Jump if equal (after compare)
  • JPN address — Jump if not equal (after compare)
  • END — End program

7. Addressing modes Immediate, Direct, Indirect, Indexed, Relative

▼

Addressing modes determine where the CPU fetches data from:

ModeSyntaxWhat it doesExample
Immediate#valueUse the value directly (no memory access)LDM #200 → ACC = 200
Direct/AbsoluteaddressFetch from the specified memory addressLDD 200 → ACC = [memory 200]
Indirectaddress with LDIAddress contains another address (pointer). Fetch from that location.Memory[200]=20, Memory[20]=5; LDI 200 → ACC = 5
Indexedaddress with LDXAddress + Index Register value = final addressIX=4, Memory[204]=17; LDX 200 → ACC = 17
Relative#offset with JMRPC + offset = jump addressJMR #5 → jump 5 locations forward
📚 Full example:
Scenario: Memory[200]=20, Memory[20]=5, IX=4
LDM #200 → ACC = 200 (immediate)
LDD 200 → ACC = 20 (direct: fetch from address 200)
LDI 200 → ACC = 5 (indirect: address 200 contains 20, so fetch from address 20)
LDX 200 → ACC = ? (indexed: fetch from 200+4=204)
Frequent Paper 1 Q Memory[200]=300, Memory[300]=50. State the contents of ACC after: (i) LDM #200 (ii) LDD 200 (iii) LDI 200
📋 Show mark scheme
(i) 200 (immediate); (ii) 300 (direct: value at 200); (iii) 50 (indirect: 200→300→50)
