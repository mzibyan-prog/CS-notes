▼

2. Client-server vs peer-to-peer Plus thin & thick clients

▼

Client-server: dedicated server(s) provide services; clients request them.

Peer-to-peer: every node can share files with every other node; no central server.

FeatureClient-serverPeer-to-peer
Central controlYes (server)No (each node equal)
SecurityEasier to manage centrallyHarder to manage
Cost / setupExpensive, needs expertiseCheap, simple
If server/peer failsServices may stopNetwork usually continues
Typical useSchools, officesSmall/home networks, file sharing

Thin client: needs network/internet to work; processing done elsewhere.

Thick client: can work offline and do its own processing.

Frequent Paper 1 Q Give two advantages and one disadvantage of a client-server network compared to peer-to-peer.
📋 Show mark scheme
Advantages: centralised security/backup, easier management, central file storage. Disadvantage: more expensive / needs expert maintenance / if server fails, network affected.

3. Network topologies Bus · Star · Mesh · Hybrid

▼

Bus topology: single central cable; each node reads every packet and ignores those not addressed to it.

  • Advantages: cheap, little cabling, easy to expand; if one node fails the rest keep working.
  • Disadvantages: if the main cable fails the whole network fails; performance drops under heavy load; insecure (every node sees every packet); needs terminators to stop signal reflection.

Star topology: every device has its own cable to a central hub/switch.

  • Advantages: if one cable fails only that device is affected; easy to add/remove nodes; consistent performance; secure (data goes only to the destination).
  • Disadvantages: central device is a single point of failure; more cabling than bus.

Mesh topology: each node connected to several others, providing multiple routes.

  • Advantages: very reliable (multiple paths), no single point of failure.
  • Disadvantages: expensive, complex wiring.

6. The internet & DNS WWW · URL · IP address · HTML

▼

The internet is a global network of networks. The WWW is the collection of web pages accessed via the internet (they are not the same thing).

URL example: https://www.example.com/folder/file.html

  • https — protocol
  • www.example.com — domain name
  • /folder/file.html — path to the file

DNS translates a domain name into an IP address.

1 User types www.example.com
2 Browser asks a DNS server for the matching IP address
3 DNS returns the IP (e.g. 203.0.113.5)
4 Browser connects to that IP to fetch the page

HTML is used to write/structure web pages. Browsers interpret HTML to display them.

Frequent Paper 1 Q Describe the purpose of the DNS.
📋 Show mark scheme
Translates a domain name into its corresponding IP address so the browser can locate the correct web server.

8. Email & other protocols SMTP · POP3 · IMAP · Ethernet · BitTorrent

▼
ProtocolPurpose
SMTPSends email (from client to server / server to server)
POP3Retrieves/downloads email from a server to a device
IMAPAccesses email kept on the server (syncs across devices)

Ethernet defines how data is sent on a wired LAN (using MAC addresses and frames).

BitTorrent is a peer-to-peer file-sharing protocol: a file is split into pieces shared between many peers.

  • Peer — a computer in the swarm.
  • Swarm — all peers sharing one file.
  • Tracker — holds details of peers in the swarm.
  • Leech — downloads without uploading.
  • Seed — has the full file and uploads it.
✏️ Past paper: "Describe the difference between SMTP and POP3" → SMTP is for sending email, POP3 is for receiving/downloading email.

9. Circuit vs packet switching Packets · Headers · Routing

▼

Circuit switching: a dedicated path is established and held for the whole communication (e.g. traditional phone calls).

Packet switching: data is split into packets; each packet travels independently and is reassembled at the destination.

Circuit switchingPacket switching
Dedicated path for whole sessionNo dedicated path
Fixed bandwidth reservedBandwidth shared
Data arrives in orderPackets may arrive out of order (reassembled)
Less efficient for burstsEfficient use of network
E.g. old telephone networksE.g. the internet

Each packet has a header with: source address, destination address, sequence number, and hop count.

1 Data is split into packets, each with a header.
2 Each packet is routed independently (may take different routes).
3 At the destination, packets are reassembled into the original data.
Frequent Paper 1 Q Explain how packet switching is used to send a web page. Describe one possible problem.
📋 Show mark scheme
Data split into packets, each with a header (source, destination, sequence no., hop count). Packets routed independently, may take different routes, reassembled at destination. Problem: packets can arrive out of order / be lost / delayed (real-time issues).
